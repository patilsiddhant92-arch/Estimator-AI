## Findings, ranked

1. **Must fix: named work is merged into the plain demo line.** `takeoff.py:38` groups by (family, action), so one
   `demolish` AHU and one `demolish_with_work` AHU print `Qty (2) AHU demo, existing controls removed`. The ruling
   says named work gets its own line. Grok's test `test_demolition.py:38-57` pins the wrong result (count 3 with the
   note). Root cause: brief step 2 says to group demolish and demolish_with_work together. Fix: key the group on
   (family, action, note) where a `demolish` unit has note "" and a `demolish_with_work` unit has its reason.
   Reviewer xfail: `test_named_work_gets_its_own_line_apart_from_plain_demo`.
2. **Must fix: Word numbers the heading, the price sheet does not.** `render.py:235` builds `Block(...)` with the
   default `numbered=True`, so Word's outline prints "N. Demolition Scope". `rows.py:55` skips `next(numbers)` for
   it, so the price sheet prints no number. The two documents disagree. wave2's "Labor Conditions" block uses
   `numbered=False` (`bms/labor.py labor_block`). Fix: `numbered=False`. Reviewer xfail:
   `test_the_demolition_heading_takes_no_number`.
3. **Lead ruling: "last block".** `render.py:201` appends the block to the base bid. Add and deduct alternates print
   after it (`proposal/write.py:75`), so on a job with alternates it is not last. After the merge with wave2,
   `with_labor` (`run.py` after `render`) also appends "Labor Conditions" after it. Rule the order: Demolition
   Scope last of the base bid, or after Labor Conditions, or after the alternates.
4. **Should fix: the price-sheet row is found by header text.** `rows.py:55` matches `squash(block.header) ==
   "Demolition Scope"`. A system block with that name would lose its numbering and prices. Each labor row also gets
   a `PRICE PENDING` flag (exact-key lookup, `price_book.py:101`) and counts in the Summary's pending total. The
   estimator fills hours, not a price. Consider a block flag and no price lookup for these rows.
5. **Lead ruling: the note is `Unit.reason`.** `Unit.reason` is "Why, in one short sentence" (wave2 `model.py:300`),
   not the named work. It prints in client text. The brief asked for this; the takeoff prompt
   (`prompts/takeoff_job.md:15`) should ask for the named work in the documents' words for `demolish_with_work`.
6. **Minor.** The price-sheet text drops the note (`rows.py:72-76`, per the brief): after fix 1, two lines can match.
